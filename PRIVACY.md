# Privacy Policy

ChatGPT Timeline Search is designed to run locally in your browser on ChatGPT conversation pages.

## Data Collection

This extension does not collect, sell, transmit, or share your ChatGPT conversation content.

## Local Processing

The extension reads the currently loaded ChatGPT page DOM to build an in-page timeline and search index. Search, filtering, and jump behavior happen inside the current browser tab.

## Storage

The extension stores only lightweight UI preferences in browser local storage, such as whether the panel is pinned open and whether assistant messages are included in the timeline. It does not store conversation content.

## Network Requests

The extension does not make external network requests.

## Permissions

The extension requests access only to ChatGPT domains so it can inject the timeline panel into those pages.

## Contact

Open a GitHub issue in this repository for privacy questions or bug reports.
