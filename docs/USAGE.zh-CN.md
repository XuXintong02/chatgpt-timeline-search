# 使用说明

## 安装开发版扩展

1. 下载或 clone 本项目到本地。
2. 打开 Chrome 或 Edge。
3. 进入扩展管理页：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
4. 打开右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择项目根目录，也就是包含 `manifest.json` 的文件夹。
7. 打开或刷新 ChatGPT 页面。
8. 在聊天页面右侧看到浅灰色时间轴标记后，说明扩展已运行。

## 基本操作

- 鼠标移动到页面右侧浅灰色标记区域，会展开时间轴面板。
- 点击时间轴条目，会跳转到该轮对话的用户需求起始处。
- 输入关键词可以筛选当前已加载的会话内容。
- 默认只展示用户消息。
- 勾选“显示 ChatGPT 回复”后，会同时展示模型回复。
- 点击“向上扫描”可以尝试加载更早的历史消息并重新索引。
- 使用 `Ctrl/Command + Shift + F` 可以打开并聚焦搜索框。
- 点击浏览器工具栏中的扩展图标可以固定或取消固定面板。

## 当前限制

- 扩展只能索引 ChatGPT 页面当前已经加载到 DOM 中的消息。
- ChatGPT 网页结构变化时，索引逻辑可能需要跟随更新。
- 时间轴表示消息顺序，不代表真实发送时间，因为页面没有稳定暴露每条消息的时间戳。
